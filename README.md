# 新北市立頭前國中 116年會考全校模擬考落點預估與弱點診斷系統

本專案為新北市立頭前國中 116 學年度九年級國中教育會考模擬考成績查詢、五科弱點精準診斷與公立高中職落點預估系統。

---

## 📌 系統特色

1. **涵蓋全校 16 班（901 ~ 916 班共 421 位學生）**。
2. **精準落點預估**：
   - 依據 **林群數學 115 年國中會考落點積分預估表**。
   - 結合校內能力等級中 **不含作文區排**、**不含作文區男排**、**不含作文區女排** 與總積分進行嚴格性別隔離與名額排位對齊。
3. **全面公立學校志願**：
   - 100% 推薦優質公立普通高中與技術型高中，嚴格排除私立學校。
   - 標註高中職 07:30 前到校早自習規範。
   - 基隆區跨縣市學校特別標示建議出門時間（避免等火車或塞車遲到）。
4. **雙模式架構**：
   - **家長個別查詢**：需輸入班級、座號、姓名及身分證後3碼進行多重驗證，保障個資安全。
   - **導師專區**：各班導師專屬密碼登入檢視該班名冊；907 班導師具全校管理切換權限。

## 🚀 GitHub Pages 啟用與上線步驟

1. 將本專案上傳至 GitHub 儲存庫（Repository）。
2. 進入儲存庫頁面，點選頂部 **Settings**（設定）。
3. 在左側選單點選 **Pages**。
4. 在 **Build and deployment** 下方的 **Source** 選擇 `Deploy from a branch`。
5. **Branch** 選擇 `main`（或 `master`），資料夾維持 `/ (root)`，點選 **Save**（儲存）。
6. 等候約 1~2 分鐘，上方即會出現您的專屬上線網址（例如：`https://<您的帳號>.github.io/<儲存庫名稱>/`）。
